# Commute Guardian

## Overview

Commute Guardian is a smart commuting assistant designed for fixed-route commuters.

It monitors:
- MRT disruptions
- Bus arrivals
- Traffic incidents
- Weather conditions

and alerts users only when disruptions significantly affect their normal journey.

## Features

- Route monitoring
- Bus arrival information
- MRT service status
- Traffic incident alerts
- Weather updates
- Journey simulation
- User route preferences

## Tech Stack

- React
- TypeScript
- Supabase
- Leaflet Maps
- Tailwind CSS
