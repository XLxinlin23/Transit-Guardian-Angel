# Component Structure

## Alert Components

CommuteAlertCard.tsx

Purpose:
Displays important commuting disruption alerts.

## Transport Components

BusArrivalCard.tsx
MrtStatusCard.tsx

Purpose:
Displays live transport information such as bus arrival timings and MRT service status.

## Location Components

NearbyBusStopCard.tsx
NearbyMrtStationsCard.tsx
PlacePicker.tsx

Purpose:
Allows users to find and select nearby transport locations.

## Route Components

RouteMap.tsx
RouteLeafletMap.tsx
JourneySteps.tsx
JourneyStatusCard.tsx

Purpose:
Displays journey routes, commute progress, and map visualizations.

## User Preference Components

RoutePreferencePanel.tsx
RouteAlarmForm.tsx
SettingsSheet.tsx

Purpose:
Allows users to configure route preferences and alert settings.

## Monitoring Components

TrafficIncidentsCard.tsx
WeatherCard.tsx

Purpose:
Monitors external conditions that may affect the user's commute.

## Simulation Components

SimulationView.tsx

Purpose:
Simulates possible disruption scenarios and route outcomes.
